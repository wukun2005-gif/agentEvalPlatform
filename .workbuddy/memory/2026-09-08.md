# 2026-09-08

## 修复「一键演示」(demo-overlay) 的多个 bug

用户反馈：从「跨租户越权」示例开始 playground 展示不完整（看不到 query 和 eval 结果就跳到下一个）；
triage/drift/dashboard 只有 tooltip 文本、没有真正的界面展示。

### 根因与修复

1. **LLM 输出撑爆页面**（`public/components/replay.js`）
   - `test-latency-fail` fixture 返回 8000 个 'x'，`写一篇长文` 返回 2434 字符，
     renderStepDetail 的 `case "llm"` 直接全量渲染，把整个页面铺满，后续步骤全被遮住。
   - 修复：截断到 280 字符 + `.demo-llm-tail` 折叠 + "展开/收起" 切换；
     输出区和 LLM context 区都加 `max-height: 240px; overflow: auto` 兜底。
   - 保留 `.hallucinated` 高亮（绩效 A / 涨薪 8%），只对截断后的片段生效。

2. **切页 hash 格式错误**（`public/components/demo-overlay.js`）
   - 旧代码 `location.hash = "#" + page` → 产生 `#triage`；
     但 `app.js` 的 `route()` 用 `location.hash.replace("#/", "")`，只认 `#/triage`。
     → `ROUTES[undefined]` 回落 replay，所以永远停在 playground，只剩 tooltip。
   - 修复：`"#/" + step.page`。

3. **没等异步页面渲染**
   - `route()` 是同步调用但各 component 是 async render，旧代码只等 1000ms。
   - 修复：新增 `waitForPage(page, maxMs=4000)`，轮询目标页核心 DOM
     （`#qInput` / `#dashContent` / `#triageContent` / `#driftContent`）挂载完成。

4. **原 DEMO_SCRIPT 根本没有 Drift 段落** — 只有 Dashboard 和 Triage。已补上 Drift 段。

5. **Tooltip 全塞屏幕中央** — 新增 `pointTo(el, text)`，让光标/tooltip 跟随真实元素：
   `pointGate`(Gate badge)、`pointEvPack`、`pointStat`、`pointTriage`、`pointDrift`。

6. **加了视觉进度反馈** — `.demo-active-example`（示例 pill 脉冲高亮）、
   `.demo-active-page`（侧边栏当前页高亮），CSS 在 `public/styles.css`。

7. 修正示例 5/6 的文案：fixture 模式下 latency 只有 50ms 恒 PASS，
   实际失败的是 cost，原标签「Latency 超时」是错的，已改为「Cost 超预算」。

### 环境坑
- 本机有 HTTP 代理（`$HTTP_PROXY=http://127.0.0.1:61480`）会拦截 localhost 请求返回 502，
  curl 直连测不通；沙箱也限制网络。验证改用 `node -e` 直接 require 模块跑逻辑。
- `npm run dev` 用 `--watch public`，改静态文件后**刷新浏览器即可**，无需重启 server
  （express.static 也是每次请求读盘）。
